VANDANA'S ROMANTIC BIRTHDAY WEBSITE 💗

This is the bright, romantic pink/purple version.
Preview: open index.html in Chrome or Edge.
To publish: create a PUBLIC GitHub repository, upload index.html, then open Settings → Pages.
Choose "Deploy from a branch", select branch main and folder /(root), then Save.
Wait a minute or two and use the GitHub Pages link.

Edit index.html in VS Code if you want to change the message. Google Fonts needs an internet connection.
